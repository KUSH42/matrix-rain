# SPEC-mossad-mode

**Status**: Draft
**Priority**: P2 — easter egg / fun
**Depends on**: ccp-easter-egg (pattern reference only — no code dependency)
**Goal**: Typing "bibinetanyahu" triggers Mossad mode — Netanyahu ASCII art billboards appear in blue/white, the rain shifts to an Israeli colour scheme with Hebrew glyphs, a surveillance HUD overlays the viewport, and an optional Hatikvah tone sequence plays.

---

## Problem

The demo has a CCP easter egg. We want a parallel Israeli-themed mode that follows the same architecture (keylogger → handle method → library) but uses a completely different visual and cultural language:

1. Blue/white colour palette instead of red.
2. Netanyahu braille/ASCII portraits instead of Xi Jinping.
3. Hebrew charset for the rain columns.
4. Mossad surveillance aesthetic HUD (target reticle, intercept counter, classification stamp).
5. Israeli flag canvas billboard instead of PRC flag.

---

## Goals

1. Typing `bibinetanyahu` (case-insensitive, no spaces) in any focus state toggles Mossad mode on/off.
2. On activation:
   a. 3 large canvas-texture billboard planes appear in the distant background (radius 21–24), each displaying a Netanyahu braille ASCII art portrait in blue/white, flashing at a configurable rate.
   b. A 4th billboard displays a canvas-drawn Israeli flag (blue stripes, Star of David).
   c. A `#mossad-hud` DOM element (fixed top banner) shows a target callsign, REC indicator, intercept counter incrementing in real time, and mouse-position displayed as "coordinates".
   d. A `#mossad-tint` div washes the entire viewport with a faint blue tint (~3% opacity).
   e. Two horizontal scan bars sweep from bottom to top continuously (inverse of CCP's top-to-bottom direction).
   f. `showMessage()` cycles Mossad-flavoured slogans while active.
   g. Opt-in: Web Audio API sine-wave rendition of the opening bars of Hatikvah loops while active.
3. Rain scene override (default on, gateable by checkbox):
   a. Rain primary colour → `#0038B8` (Israeli blue).
   b. Rain secondary/head colour → `#FFFFFF` (white).
   c. Charset → `'hebrew'` (requires a Hebrew MSDF atlas — see §Hebrew charset below).
   d. Columns remain downward (`reverseChance` unchanged).
   e. Vignette → 0.75.
   f. Holo aberration → 0.008.
4. A hidden `#mossad-panel` div in the settings panel appears on activation.
5. A transient hint `[ MOSSAD MODE ACTIVATED ]` / `[ MOSSAD MODE DEACTIVATED ]` in blue for 2 s at bottom-left.
6. Everything cleans up completely on deactivate or `destroyMatrixRain`.

## Non-Goals

- No shader changes. All planes use `THREE.MeshBasicMaterial` — no TSL, no MSDF for portraits.
- No modification to `matrix-rain-tsl.js`, `matrix-rain-passes-tsl.js`, or `matrix-rain-presets.js`.
- No persistence across page reloads.
- The Hebrew atlas is generated by the existing `tools/gen-atlas.html` tool — no new tooling.
- Actual audio is a pure sine-wave sequence via Web Audio — no audio file assets.

## Design

### A. Trigger — keylogger in `matrix-3d.html`

Rolling 13-character lowercase buffer. Buffer clears after 3 s of inactivity.
On match of `'bibinetanyahu'` the buffer is cleared and Mossad mode is toggled:

```js
let _mbuf   = '';
let _mTimer = null;
document.addEventListener('keydown', e => {
  if (e.ctrlKey || e.altKey || e.metaKey || e.key.length !== 1) return;
  _mbuf = (_mbuf + e.key.toLowerCase()).slice(-13);
  clearTimeout(_mTimer);
  _mTimer = setTimeout(() => { _mbuf = ''; }, 3000);
  if (_mbuf === 'bibinetanyahu') {
    _mbuf = '';
    _mossadActive = !_mossadActive;
    rain.setMossadMode(_mossadActive);
    // show/hide panel, flash hint (see §HTML section)
  }
});
```

### B. Netanyahu ASCII art constants — `MOSSAD_ART` in `matrix-rain-webgpu.js`

Three multiline strings, each a well-known Netanyahu Unicode braille copypasta,
stored as a module-level `const MOSSAD_ART` array. Each entry uses Unicode braille
characters (U+2800–U+28FF) — same character class as `CCP_ART`:

- `MOSSAD_ART[0]` — full portrait (~32 lines × 46 chars)
- `MOSSAD_ART[1]` — compact bust variant (~20 lines × 38 chars)
- `MOSSAD_ART[2]` — dense fill portrait (~28 lines × 42 chars)

### C. Canvas texture builders

#### `buildMossadPortraitTexture(artStr)`

```
buildMossadPortraitTexture(artStr) → THREE.CanvasTexture
```

- Canvas: `768 × 512` px, transparent background.
- Font: `'16px monospace'`, fill style `#3060FF` (vivid Israeli blue).
- Text rendered centred horizontally, `yStep = canvas.height / (lines.length + 2)`.
- Returns a `THREE.CanvasTexture` with `needsUpdate = true`.

#### `buildIsraeliFlag()`

```
buildIsraeliFlag() → THREE.CanvasTexture
```

Draw a simplified Israeli flag programmatically on a `640 × 427` canvas (3:2 flag aspect):

1. Fill entire canvas `#FFFFFF`.
2. Draw top blue stripe: `fillRect(0, 85, 640, 64)` with fill `#0038B8`.
3. Draw bottom blue stripe: `fillRect(0, 278, 640, 64)` with fill `#0038B8`.
4. Draw Star of David (Magen David) centred at `(320, 213)`:
   - Two equilateral triangles, each with circumradius `72` px, fill `#0038B8`.
   - Triangle 1 (up-pointing): vertices at angle `−90°, 30°, 150°`.
   - Triangle 2 (down-pointing): vertices at angle `90°, 210°, 330°`.
   - Draw triangle 1 path, fill; draw triangle 2 path, fill.
   - Draw inner hexagon in white to cut the overlap and form the classic star shape:
     vertices at `0°, 60°, 120°, 180°, 240°, 300°` at circumradius `41.6` px.
5. `tex.needsUpdate = true`.

### D. Plane meshes

Portrait panels (3 units):
```
geom = new THREE.PlaneGeometry(panelW, panelH)
mat  = new THREE.MeshBasicMaterial({
  map:         canvasTex,
  transparent: true,
  opacity:     0,
  depthWrite:  false,
  side:        THREE.DoubleSide,
  blending:    THREE.AdditiveBlending,
})
```
`panelW = 16 * _mossadScale`, `panelH = panelW * (512 / 768)`.

Flag panel (1 unit):
Same geometry/material setup, `panelW = 14 * _mossadScale`, `panelH = panelW * (427 / 640)`.
`blending: THREE.NormalBlending` (flag should look opaque, not additive).

### E. Panel positions and phases

Four panels at fixed azimuths outside the rain shell:

| idx | Type       | Azimuth (rad) | Radius | Y offset | Flash phase (rad) |
|-----|------------|--------------|--------|----------|-------------------|
| 0   | Portrait   | 0.0          | 22     | +1.5     | 0.0               |
| 1   | Portrait   | 2.094 (120°) | 24     | −1.0     | 2.094             |
| 2   | Portrait   | 4.189 (240°) | 21     | +2.5     | 4.189             |
| 3   | Flag       | 1.047 (60°)  | 23     | +0.5     | 1.047             |

Position: `x = Math.sin(az) * r`, `y = yOffset`, `z = -Math.cos(az) * r`.

The flag panel uses `NormalBlending` and a fixed opacity of `_mossadPeakOpacity * _mossadFadeT` (no flash).

### F. Mossad state in `initMatrixRain` closure

```js
let _mossadActive           = false;
let _mossadFadeT            = 0;
let _mossadFadeDir          = 0;      // +1 / -1 / 0
let _mossadPanels           = [];     // { mesh, canvasTex, az, r, phase, yBase, type }
let _mossadFlashHz          = 0.9;
let _mossadPeakOpacity      = 0.68;
let _mossadScale            = 1.0;
let _mossadPanelCount       = 3;      // portrait count 1–3 (flag is always added separately)
let _mossadOrbitSpeed       = 0.0;
let _mossadOrbitAngle       = 0.0;
let _mossadRainOverride     = true;
let _mossadSaved            = null;   // { colorR/G/B, color2R/G/B, charSet, vignette, aberration }
let _mossadSloganIdx        = 0;
let _mossadAudioEnabled     = false;
let _mossadAudioCtx         = null;
let _mossadCounterInterval  = null;
```

`_mossadScanStyleInjected` is **module-level** (outside `initMatrixRain`):

```js
let _mossadScanStyleInjected = false;  // module-level — survives re-initialisation
```

### G. Per-frame update in `tick(t)`

```js
// ── Mossad mode panel animation ──────────────────────────────────────────
if (_mossadFadeDir !== 0 || _mossadPanels.length > 0) {
  if (_mossadFadeDir !== 0) {
    const speed = _mossadFadeDir > 0 ? (1 / 0.8) : (1 / 0.5);
    _mossadFadeT = Math.max(0, Math.min(1, _mossadFadeT + _mossadFadeDir * dt * speed));
    if (_mossadFadeT <= 0 && _mossadFadeDir < 0) {
      _destroyMossadPanels();
      _mossadFadeDir = 0;
    }
    if (_mossadFadeT >= 1) _mossadFadeDir = 0;
  }
  _mossadOrbitAngle += _mossadOrbitSpeed * dt;
  for (let i = 0; i < _mossadPanels.length; i++) {
    const p  = _mossadPanels[i];
    const az = p.az + _mossadOrbitAngle;   // az baked at init — no _MOSSAD_POSES[i] index dependency
    const r  = p.r;
    p.mesh.position.set(Math.sin(az) * r, p.yBase + Math.sin(t * 0.35 + p.phase) * 0.4, -Math.cos(az) * r);
    p.mesh.quaternion.copy(camera.quaternion);
    if (p.type === 'portrait') {
      const flash = 0.5 + 0.5 * Math.sin(t * _mossadFlashHz * Math.PI * 2 + p.phase);
      p.mesh.material.opacity = _mossadPeakOpacity * flash * _mossadFadeT;
    } else {
      // flag: no flash, just fade
      p.mesh.material.opacity = _mossadPeakOpacity * _mossadFadeT;
    }
  }
}
```

### H. `_initMossadPanels()` / `_destroyMossadPanels()` helpers

`_initMossadPanels()`:
- Create `_mossadPanelCount` portrait panels using `MOSSAD_ART[i % 3]`.
  For portrait `i`, bake pose from `_MOSSAD_POSES[i]`: `{ ..., az: pose.az, r: pose.r, phase: pose.phase, yBase: pose.yOffset }`.
- Always append 1 flag panel using `buildIsraeliFlag()`.
  Flag panel always bakes from `_MOSSAD_POSES[3]` explicitly — **never** uses `_mossadPanelCount` as the index.
- Each entry stored as `{ mesh, canvasTex, az, r, phase, yBase, type: 'portrait'|'flag' }`.
- Add all meshes to `scene`.

`_destroyMossadPanels()`:
- For each panel: `scene.remove`, `geometry.dispose()`, `material.dispose()`, `canvasTex.dispose()`.
- `_mossadPanels = []`.
- Also called from `_cleanup()`.

`_cleanup()` full checklist:
- `_destroyMossadPanels()` — removes meshes and disposes textures.
- `clearInterval(_mossadCounterInterval); _mossadCounterInterval = null;`
- `if (_mossadAudioCtx) { _mossadAudioCtx.close(); _mossadAudioCtx = null; }`
- Remove `#mossad-hud`, `#mossad-tint`, `#mossad-scan-a`, `#mossad-scan-b` DOM nodes if present.
- Remove mousemove coordinate listener if attached.

### I. Rain scene override in `setMossadMode`

**On activate** — save and apply (only if `_mossadRainOverride`):
```js
_mossadSaved = {
  colorR: uniforms.uColor.value.x,  colorG: uniforms.uColor.value.y,  colorB: uniforms.uColor.value.z,
  color2R: uniforms.uColor2.value.x, color2G: uniforms.uColor2.value.y, color2B: uniforms.uColor2.value.z,
  charSet: _currentCharSet,
  vignette: _ppState.vignette,
  aberration: _ppState.aberration,
};
handle.setColor('#0038B8');        // Israeli blue
handle.setColor2('#FFFFFF');       // White head
handle.setCharSet('hebrew');       // Hebrew glyph atlas
handle.setVignette(0.75);
handle.setHoloAberration(0.008);
```

**On deactivate** — restore:
```js
if (_mossadSaved) {
  handle.setColor(toHex(_mossadSaved.colorR, _mossadSaved.colorG, _mossadSaved.colorB));
  handle.setColor2(toHex(_mossadSaved.color2R, _mossadSaved.color2G, _mossadSaved.color2B));
  handle.setCharSet(_mossadSaved.charSet);
  handle.setVignette(_mossadSaved.vignette);
  handle.setHoloAberration(_mossadSaved.aberration);
  _mossadSaved = null;
}
```

### J. `#mossad-hud` DOM element

Fixed div at top of viewport, similar to `#ccp-hud`. Shown on activate, removed on deactivate.

```html
<div id="mossad-hud">
  <span id="mossad-callsign">◈ UNIT 8200 — OPERATION WRATH OF GOD ◈</span>
  <span id="mossad-rec">⬤ INTERCEPT</span>
  <span id="mossad-counter">SIGNALS: <span id="mossad-count">0</span></span>
  <span id="mossad-coords">POS: <span id="mossad-xy">0,0</span></span>
</div>
```

Styling (inline on the element):
- `position: fixed; top: 0; left: 0; right: 0; z-index: 9999`
- `background: rgba(0,30,100,0.55); color: #7EB3FF`
- `font: 11px monospace; padding: 4px 12px; display: flex; gap: 24px; align-items: center`
- `border-bottom: 1px solid #0038B855`

Update logic (attached in `matrix-3d.html`, removed on deactivate):
- Intercept counter increments by a random 1–3 every ~800 ms:
  `_mossadCounterInterval = setInterval(() => { count += Math.ceil(Math.random()*3); countEl.textContent = count; }, 800);`
  Store the interval ID; `clearInterval(_mossadCounterInterval)` on deactivate and in `_cleanup()`.
- Mouse coordinates tracked via `mousemove` on `document`; listener removed on deactivate.
- `⬤ INTERCEPT` pulses opacity 1→0.3→1 on a 1.2 s CSS animation.

### L. Scan bars

Two `<div>` elements (`#mossad-scan-a`, `#mossad-scan-b`) with:
```css
position: fixed; left: 0; right: 0; height: 2px;
background: rgba(126,179,255,0.15); pointer-events: none; z-index: 9991;
animation: mossadScan 3.5s linear infinite;
```
`@keyframes mossadScan { from { top: 100% } to { top: -2px } }` (bottom-to-top, inverse of CCP).
`#mossad-scan-b` uses `animation-delay: -1.75s` for a half-period offset.

The `<style>` block for `mossadScan` is injected into `<head>` on first activate and remains (idempotent re-injection guard via the module-level flag `_mossadScanStyleInjected`; set to `true` after first inject, never reset — prevents duplicate `<style>` across re-initializations of the rain instance).

### M. Message reveal slogans

While Mossad mode is active, `showMessage()` cycles through 5 slogans (looping):

```js
const MOSSAD_SLOGANS = [
  'BY DECEPTION THOU SHALT MAKE WAR',
  'OPERATION WRATH OF GOD',
  'WHO DARES TO TOUCH ME',
  'IRON DOME',
  'FROM THE NILE TO THE EUPHRATES',
];
```

Behaviour identical to CCP slogan cycling: on each `showMessage()` completion, the
next slogan is queued automatically using `_mossadSloganIdx` (0–4, wraps).
Slogans are cleared (no next message) when Mossad mode is deactivated.

### N. Hatikvah tone sequence (opt-in)

Web Audio API, same architecture as CCP's anthem:

```js
const HATIKVAH_NOTES = [
  // Opening bars — relative semitones from D4 (MIDI 62), duration ms
  // D4, E4, F4, G4, A4, G4, F4, E4, D4 ...
  // (simplified pentatonic excerpt representing the opening phrase)
  [62,400],[64,400],[65,400],[67,400],[69,400],[67,400],[65,400],[64,400],
  [62,600],[62,200],[64,400],[65,400],[67,800],
];
```

Play on a loop using `AudioContext` with a `setTimeout` chain. Stop when
`_mossadAudioCtx.close()` is called on deactivate (or mode destruction).
Gated by `_mossadAudioEnabled` (default `false`; controlled by checkbox in `#mossad-panel`).

## Hebrew charset

### Problem

No Hebrew MSDF atlas exists yet. The rain glyph shader uses the existing `charSet` system
(atlas PNG + grid dimensions). A Hebrew atlas must be added before `setCharSet('hebrew')`
works.

### Solution

1. Add a `hebrew` entry to `data/glyph-sets.js`:
   ```js
   hebrew: {
     label:  'Hebrew',
     chars:  'אבגדהוזחטיכלמנסעפצקרשת׀׃ ָ ִ ֵ ֶ ַ ָ ֹ ּ',
     grid:   { w: 8, h: 8 },
   }
   ```
   This is the 22 Hebrew letters (aleph–tav) plus punctuation/cantillation marks,
   filling a 64-slot 8×8 grid (same as `matrix1999`).

2. Generate `data/hebrew_msdf.png` and `data/hebrew_bitmap.png` using `tools/gen-atlas.html`
   (same procedure as other sets). Commit both PNGs.

3. Register the charset in `CHAR_SETS` in `matrix-rain-webgpu.js`:
   ```js
   hebrew: { atlas: 'data/hebrew_msdf.png', gridW: 8, gridH: 8 },
   ```

4. Expose `'hebrew'` in the `setCharSet` docstring.

## Cost Impact

- 4 extra draw calls per frame (3 portraits + 1 flag) — negligible.
- 3 canvas portrait textures at `768×512` + 1 flag texture at `640×427`: ~5.5 MB GPU total.
- Hatikvah: negligible (oscillator nodes, no audio buffer).
- DOM: 3 small fixed elements, no layout pressure.
- Zero cost when Mossad mode is off.

---

## Error Conditions

| Scenario | Handling |
|---|---|
| `setMossadMode(true)` called twice | `_initMossadPanels` no-op if `_mossadPanels.length > 0` |
| `destroyMatrixRain` while active | `_cleanup` calls `_destroyMossadPanels`, removes HUD DOM nodes |
| `setCharSet('hebrew')` before atlas PNG exists | `setCharSet` logs `console.warn` and returns without changing charset (existing guard behaviour) |
| `setMossadScale` / `setMossadPanelCount` while fading out | Only rebuild if `_mossadActive === true` |
| Web Audio not supported | `try/catch` around `new AudioContext()`; audio silently disabled |

---

## Backward Compatibility

No existing API changes. `setMossadMode` and companion methods are new. CCP mode and Mossad mode are fully independent — they can coexist in the scene simultaneously (both sets of panels visible, rain takes the most-recently-applied override).
