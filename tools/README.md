# tools/

## Atlas generation

MTSDF atlases for the matrix rain shader are generated by `gen-atlas-cli.js` using the
`msdf-atlas-gen` binary (bundled in `node_modules/msdf-atlas-gen/bin/`).

```
npm run gen-atlas              # regenerate all sets
npm run gen-atlas:set latin    # single set
npm run gen-atlas:set all      # explicit all
```

Generated PNGs are written to `data/`. Each is a 4-channel RGBA MTSDF atlas where RGB
stores the multi-channel SDF and A stores the true single-channel SDF for small-scale
fallback (MTSDF format, msdf-atlas-gen v1.3+).

## Font setup

Fonts are gitignored (`data/fonts/`). Before running atlas generation:

### Bundled fonts (from project zip)

Extract `Datatype,Google_Sans_Code,Iosevka_Charon_Mono,Orbitron.zip` into `data/fonts/`:

```bash
unzip ~/Datatype,Google_Sans_Code,Iosevka_Charon_Mono,Orbitron.zip -d data/fonts/
```

Expected layout after extraction:

```
data/fonts/
  Datatype/static/Datatype-Regular.ttf
  Google_Sans_Code/static/GoogleSansCode-Regular.ttf
  Iosevka_Charon_Mono/IosevkaCharonMono-Regular.ttf
  Orbitron/static/Orbitron-Bold.ttf
```

### Noto fonts (download required)

The `cyber`, `japanese`, and `matrix1999` sets use **Noto Sans JP** (covers Cyrillic,
Greek, hiragana, katakana, and CJK). The `chinese` set uses **Noto Sans TC** (Traditional
Chinese).

Download both from Google Fonts and place the Regular weight TTF at:

```
data/fonts/noto/NotoSansJP-Regular.ttf
data/fonts/noto/NotoSansTC-Regular.ttf
```

Direct download links (click "Download family", extract the TTF):
- Noto Sans JP: https://fonts.google.com/noto/specimen/Noto+Sans+JP
- Noto Sans TC: https://fonts.google.com/noto/specimen/Noto+Sans+TC

Or via curl (substitute the correct download URL from Google Fonts):
```bash
mkdir -p data/fonts/noto
# Download NotoSansJP-Regular.ttf and NotoSansTC-Regular.ttf to data/fonts/noto/
```

## gen-atlas.html

`gen-atlas.html` generates **bitmap** atlases only (for canvas-2D rain).
MTSDF atlas generation requires the Node.js CLI (`gen-atlas-cli.js`).
